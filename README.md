# Llave del Clausura 2026

Simulador de la llave de playoffs del Torneo Clausura 2026 de la Liga Profesional Argentina.
Página estática (un solo `index.html`), sin build ni base de datos.

- Tocá un equipo para que avance; tocalo de nuevo para deshacer.
- "Simular lo que falta" completa los partidos con resultados y penales.
- Las chances de campeón salen de 20.000 simulaciones con tus elecciones fijas.
- Lo que elegís se guarda en el navegador (localStorage).

## Deploy

Importá el repo en Vercel: framework "Other", sin build command. Se publica tal cual.
